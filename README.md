# Cv Putrisinta

Buatkan landing page CV/Portofolio pribadi menggunakan React, Vite, dan Tailwind CSS. Buat layout Single Page Application dengan Navbar lengket (sticky) yang memiliki menu navigasi (Beranda, Tentang, Pengalaman, Portofolio, Kontak). Buat Hero section yang menarik dengan foto profil, nama, role, dan tombol 'Download CV'. dengann data berikut, buatlah web dengan nuansa biru
